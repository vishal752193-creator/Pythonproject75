# Python Quiz Game

A simple quiz game made using Python and Streamlit.

## Features
- Easy, Medium and Hard levels
- Choose 1–50 questions
- Random questions
- Check answers and score
- Shows percentage and time taken
- Answer review after the quiz
- Play again option

## Tech Used
- Python
- Streamlit

## Run

pip install streamlit
streamlit run app.py
